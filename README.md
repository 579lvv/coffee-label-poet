# coffee-label-poet

Website: https://579lvv.github.io/coffee-label-poet/

This repository is the independently deployable static website. `preview.html` is used by the resume when present.

The source project and build script are maintained locally in `portfolio.vv`; run `split_pages.py --sites coffee-label-poet` to rebuild this site. GitHub Pages serves `main` from the repository root. AI backend services are not hosted by Pages.
